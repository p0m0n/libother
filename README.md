**Время**:
   - `TimeSpan` — Представляет интервал времени (длительность), измеренный в тактах.
   - `DateTime` — Представляет момент времени, обычно выраженный в виде даты и времени суток.

**Таймеры**:
   - `Timer`         — Базовый класс управления логикой таймеров.
   - `ThreadTimer`   — Потокобезопасный контроллер для управления таймерами.
   - `IntervalTimer` — Класс для отсчета повторяющихся временных интервалов.
   
**Сеть**:
   - `Socket`        — Кроссплатформенная обертка сетевого сокета.
   - `SocketSelector`— Инструмент мультиплексирования для синхронного мониторинга группы сокетов.
   - `StreamSocket`  — Кроссплатформенный потоковый адаптер для сокетов.
   
**Кодирование**:
   - `base`          — Набор алгоритмов кодирования и декодирования бинарных данных (Base16, Base26, Base32 / Hex / Crockford, Base36, Base45, Base58 Bitcoin / Flickr / Ripple, Base62, Base64 / URL, Base85 Math / Z85 / ASCII85 / PDF).
