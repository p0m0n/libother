**Время**:
   - `TimeSpan` — Представляет интервал времени (длительность), измеренный в тактах.
   - `DateTime` — Представляет момент времени, обычно выраженный в виде даты и времени суток.

**Таймеры**:
   - `Timer`         — Базовый класс управления логикой таймеров.
   - `ThreadTimer`   — Потокобезопасный контроллер для управления таймерами.
   - `IntervalTimer` — Класс для отсчета повторяющихся временных интервалов.
   
**Сеть**:
   - `Socket`        — Кроссплатформенная обертка сетевого сокета (Windows/Linux) с поддержкой конфигурации опций и телеметрии жизненного цикла.
